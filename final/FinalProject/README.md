This project is pretty simple and is laid out like so:
1) Character Creation
2) Quest Creation
3) Saving and Loading

1) You start the program by creating a character with a name and choosing one of three classes: Warrior, Mage and Rogue. You can only have one character at a time for right now. Your character will have a level, XP counter, and total points. As your XP goes up, so does your level.

2) You can have three different kinds of quests: simple, collection, and boss. You start out with three basic ones, but can add more in the menu, each with their own name, description, and points (for the collection quests, you can add how many times it must be completed before the points are awarded).

3) As stated above, you can only save one character at the moment, but you can load that progress and have everything you've completed, even the quests you added.
